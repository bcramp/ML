# HW 5
Assignment 5: Diabetes Classification using Ensemble Learning and Random Forests

## Description
This folder contains assignment 5's notebook (diabetes.ipynb) and analysis (Analysis.ipynb). A "data" sub-folder was added to show what CSV file was utilized for this assignment. There were 2 files online, so I defaulted to using the OpenML Pima Indians Diabetes Database (https://www.openml.org/search?type=data&sort=runs&id=37&status=active) over the UCI Diabetes dataset (https://archive.ics.uci.edu/dataset/34/diabetes) since UCI did not have the original dataset anymore.
